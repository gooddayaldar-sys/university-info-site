# Их сургуулийн мэдээллийн веб сайт

Next.js App Router, TypeScript, CSS ашигласан хөх-цагаан загварын демо веб сайт.

## Шаардлага
- Node.js 20.9 буюу түүнээс дээш
- npm

## Ажиллуулах
1. ZIP файлыг задлаад тухайн хавтас руу орно.
2. Terminal / PowerShell нээнэ.
3. Хамаарлуудыг суулгана:

   ```bash
   npm install
   ```

4. Хөгжүүлэлтийн серверийг асаана:

   ```bash
   npm run dev
   ```

5. Хөтөчөөр http://localhost:3000 хаяг руу орно.

Production build шалгах:

```bash
npm run build
npm start
```

## Админ
Нүүр хуудасны **Нэвтрэх** товч эсвэл `/admin` хаягаар орно.

- Нэвтрэх нэр: `admin`
- Нууц үг: `admin123`

Админ хэсэгт мэдээ нэмэх, засах, устгах боломжтой. Мэдээлэл нь тухайн хөтчийн `localStorage`-д хадгалагдана.

## Анхаарах зүйл
Энэ нь интерфэйс ба үйл ажиллагааг турших демо хувилбар. Нууц үг код дотор ил тод байгаа тул бодит сайт дээр ашиглаж болохгүй. Бодит ашиглалтад:
- сервер талын authentication (жишээ нь Auth.js)
- өгөгдлийн сан (PostgreSQL / MySQL)
- API route/server actions ба сервер талын эрх шалгалт
- орчны хувьсагчид, хамгаалалт, нөөцлөлт
нэмэх хэрэгтэй. Одоогийн хувилбарын мэдээ өөр төхөөрөмж дээр автоматаар синк хийхгүй.
